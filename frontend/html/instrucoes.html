📖 Instruções de Preenchimento

Guia completo para preenchimento do formulário de entrevistas

Pesquisa · Embarcadores · PLI/SP
🎯 Objetivo do Formulário

Este formulário faz parte do Plano de Logística Integrada 2050 (PLI 2050) e tem como objetivo coletar informações detalhadas sobre as operações logísticas e de transporte de empresas embarcadoras no Brasil. Os dados coletados serão fundamentais para o planejamento estratégico da infraestrutura logística nacional.

✅ Importante

Todas as informações fornecidas serão tratadas com confidencialidade e utilizadas exclusivamente para fins de planejamento e análise estratégica do setor logístico brasileiro.

📝 Antes de Começar
⚠️ Campos Obrigatórios

Os campos marcados com asterisco (*) são obrigatórios. O sistema não permitirá salvar o formulário sem preencher todos esses campos.

💾 Salvamento no Banco de Dados PostgreSQL

Ao clicar em "💾 Salvar Respostas":

  • ✓ Os dados são validados automaticamente
  • ✓ Dados enviados para o banco PostgreSQL 17 (AWS RDS)
  • ✓ Um arquivo Excel é gerado automaticamente com 2 abas
  • ✓ O download do Excel inicia automaticamente
  • ✓ Um popup de confirmação aparecerá
  • ✓ Os dados ficam disponíveis em tempo real nas páginas "Respostas", "Analytics" e "Visualizador"

Documentos necessários:

  • 📊 Dados de movimentação anual de cargas (toneladas/ano)
  • 📍 Informações de origem e destino dos transportes
  • 💰 Custos de transporte e valores de carga
  • 📏 Distâncias percorridas (em quilômetros)
  • ⏱️ Tempos de transporte (dias, horas e minutos)
📑 Guia de Preenchimento por Seção
1 Dados do Entrevistado

Perguntas 1-4

  • Nome completo: Informe o nome completo da pessoa responsável pelas informações logísticas
  • Função: Cargo ou posição na empresa (ex: Gerente de Logística, Coordenador de Transportes)
  • Telefone: Número com DDD para contato (ex: (11) 98765-4321)
  • E-mail: E-mail corporativo ou pessoal para comunicação
2 Dados da Empresa

Perguntas 5-7

  • Tipo de empresa: Selecione o segmento (indústria, varejo, atacado, etc.). Se selecionar "Outro", especifique no campo adicional
  • Nome da empresa: Razão social ou nome fantasia
  • Município: Cidade onde a empresa está localizada (incluir estado: ex: São Paulo-SP)
3 Produtos Transportados (Tabela Dinâmica)

Pergunta 8

💡 Como usar a tabela de produtos
  1. Clique em "+ Adicionar Produto" para criar uma nova linha
  2. Preencha os 7 campos para cada produto
  3. Adicione quantos produtos forem necessários
  4. Use o botão 🗑️ para remover produtos

Campos da tabela:

Campo Descrição Exemplo
Carga Transportada Nome do produto/carga Soja, Milho, Aço, Cimento
Movimentação (ton/ano) Volume anual em toneladas 50000
Origem Cidade/Estado de origem Rondonópolis-MT
Destino Cidade/Estado de destino Santos-SP
Distância (km) Distância em quilômetros 1800
Modalidade Meio de transporte utilizado Rodoviário, Ferroviário, etc.
Acondicionamento Forma de embalagem/transporte Granel, Contêiner, Big Bag
✅ Exportação no Excel

Os produtos serão exportados em uma aba separada chamada "Produtos Transportados", facilitando a análise.

4 Produto Principal

Perguntas 9-10

  • Produto mais representativo: Dentre os produtos listados acima, indique qual tem maior relevância para a empresa (por volume ou valor)
  • Agrupamento: Selecione a categoria que melhor classifica este produto. Se necessário, selecione "Outro" e especifique
📌 Importante

As próximas perguntas do formulário (seções 5 a 8) devem ser respondidas considerando apenas este produto principal.

5 Características do Transporte

Perguntas 11-28

Origem e Destino (12-13):

  • Informe País, Estado e Município tanto da origem quanto do destino
  • Para transporte local, preencha o mesmo país/estado

Modalidades de Transporte (16):

  • Pode marcar múltiplas opções se houver transporte intermodal
  • Exemplo: Rodoviário + Ferroviário (caso use ambos)

Peso da Carga (19):

💡 Dica

Selecione a unidade correta (kg ou toneladas). O sistema converterá automaticamente para toneladas no Excel.

Custos (20-21):

  • Custo do Transporte: Valor pago pelo frete (em R$)
  • Valor da Carga: Valor da mercadoria transportada (em R$)

Tempo de Transporte (24):

  • Informe o tempo total: dias, horas e minutos
  • Exemplo: 2 dias, 5 horas, 30 minutos

Frequência (25):

  • Selecione a periodicidade das viagens
  • Se selecionar "Diária", informe quantas viagens por dia no campo adicional
6 Fatores de Decisão Modal

Perguntas 29-38

🎯 Como funciona esta seção

Para cada fator (CUSTO, TEMPO, CONFIABILIDADE, SEGURANÇA, CAPACIDADE), você deve responder:

  1. Importância: Qual o grau de importância deste fator? (Muito alta, Alta, Média, Baixa, Muito baixa)
  2. Variação %: Qual percentual de variação faria você mudar o modal de transporte? (0-100%)

Exemplo prático:

  • Importância do CUSTO: Muito alta
  • Variação % de CUSTO: 15 (significa que se o custo aumentar 15%, você consideraria trocar de modal)
💡 Sensibilidade

Valores menores (ex: 5%) indicam alta sensibilidade ao fator. Valores maiores (ex: 50%) indicam baixa sensibilidade.

7 Análise Estratégica

Perguntas 39-41

  • Tipo de Cadeia (39): Indique se é cadeia de suprimento (compra/recebimento) ou distribuição (venda/entrega)
  • Modais Alternativos (40): Pode marcar múltiplas opções. Indique quais modais você consideraria usar
  • Fator Adicional (41): Campo aberto para mencionar outros fatores importantes não listados anteriormente
8 Dificuldades Logísticas

Perguntas 42-43

  • Principais dificuldades (42): Pode marcar múltiplas opções que representem os desafios enfrentados
  • Detalhamento (43): Use este campo para explicar melhor as dificuldades ou adicionar informações relevantes
💾 Salvamento e Exportação dos Dados
1 Validação Automática

Ao clicar em "💾 Salvar Respostas", o sistema irá:

  • ✓ Verificar se todos os campos obrigatórios foram preenchidos
  • ✓ Mostrar um popup listando as perguntas não preenchidas (se houver)
  • ✓ Focar automaticamente na primeira pergunta com erro
⚠️ Atenção

Se houver campos obrigatórios vazios, o sistema não permitirá salvar até que sejam preenchidos.

2 Download Automático do Excel

Quando todos os campos estiverem preenchidos corretamente:

  • 📊 Um arquivo Excel será gerado automaticamente
  • ⬇️ O download iniciará automaticamente
  • ✅ Um popup de confirmação aparecerá com link para download
📁 Estrutura do Arquivo Excel

Aba 1 - "Respostas":

  • Cada empresa = 1 linha
  • Cada pergunta (1 a 43) = 1 coluna

Aba 2 - "Produtos Transportados":

  • Cada produto = 1 linha
  • ID da empresa para cruzar dados
  • 7 colunas com informações do produto
3 Visualização de Dados Salvos no Banco

Para visualizar dados salvos no banco PostgreSQL:

  • Clique na aba "📊 Respostas" no menu superior
  • Visualize todas as 11 pesquisas cadastradas no banco
  • Use checkboxes para mostrar/ocultar grupos de colunas
  • Clique no cabeçalho "ID ↓" para ordenar crescente/decrescente
  • Exporte os dados filtrados em Excel ou CSV
  • Aplique filtros por empresa, produto, estado ou tipo
✅ Dados em Tempo Real

A página "Respostas" consulta o banco de dados PostgreSQL em tempo real através da view v_pesquisas_completa, que traz todos os 65 campos consolidados.

4 Analytics e Análises em Tempo Real

Acesse a aba "📈 Analytics" para visualizar análises consolidadas:

  • 📊 5 KPIs principais: Total de pesquisas (11), empresas cadastradas, produtos únicos, distância média e custo médio
  • 📈 6 gráficos interativos:
    • Distribuição Modal (pizza)
    • Top 10 Produtos (barras verticais)
    • Tipo de Transporte (rosca)
    • Importância dos Fatores (radar)
    • Frequência de Transporte (barras)
    • Principais Dificuldades (barras horizontais)
  • 🎯 Dados agregados e calculados automaticamente pelo banco
  • 🔄 Atualização automática conforme novas pesquisas são cadastradas
⚡ Endpoints de Analytics

O backend FastAPI fornece 7 endpoints especializados:

  • /api/analytics/kpis - Indicadores principais
  • /api/analytics/distribuicao-modal
  • /api/analytics/produtos-top
  • /api/analytics/tipo-transporte
  • /api/analytics/importancias
  • /api/analytics/frequencia
  • /api/analytics/dificuldades
5 Visualizador de Dados Interativo

Acesse a aba "🔍 Visualizador" para consultas personalizadas:

  • 🎯 Filtros dinâmicos: Empresa, Produto, Estado de Origem e Tipo de Transporte
  • 📊 KPIs instantâneos: Pesquisas filtradas, Empresas, Produtos e Distância média
  • 📋 Tabela completa: Visualize 9 colunas principais (ID, Empresa, Produto, Origem, Destino, Distância, Modais, Tipo, Status)
  • 🔄 Consulta em tempo real: Conecta diretamente ao PostgreSQL (porta 8000)
  • 💡 Modo interativo: Aplique e limpe filtros para diferentes análises
✅ Como Usar o Visualizador
  1. Selecione os filtros desejados (ou deixe em branco para ver tudo)
  2. Clique em "🔍 Visualizar Dados"
  3. Analise os KPIs e a tabela de resultados
  4. Use "🔄 Limpar Filtros" para resetar a consulta
💡 Dicas e Boas Práticas
  • 📱 Use um computador/notebook: A interface é otimizada para telas maiores, facilitando o preenchimento da tabela de produtos
  • 🔍 Revise antes de salvar: Confira todas as informações, especialmente valores numéricos e unidades
  • 💾 Faça backup: O Excel gerado automaticamente serve como backup externo dos dados
  • 📊 Dados precisos: Forneça informações o mais precisas possível. Se não souber o valor exato, forneça uma estimativa aproximada
  • 🌐 Navegador compatível: Use Chrome, Firefox, Edge ou Safari atualizados para melhor experiência
  • 🔍 Use o Visualizador: Após salvar, confira seus dados na página "Visualizador" com filtros personalizados
  • 📈 Acompanhe no Analytics: Veja como seus dados contribuem para as estatísticas gerais do projeto
💡 Dica Pro

Prepare uma planilha com os dados antes de começar o preenchimento. Isso agiliza o processo e reduz erros.
